# Getting started

1. Install Python (see [pyproject.toml](./pyproject.toml) for up to date Python version requirements.
2. Set up a venv with `python3 -m venv venv` and activate it with `source venv/bin/activate`.
3. Install the dev dependencies `pip install -r requirements-dev.txt`
4. Install the `pre-commit` hooks: `pre-commit install --install-hooks`
